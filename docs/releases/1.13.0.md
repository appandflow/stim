# 1.13.0

## New

- `stim web` opens the workspace's web app in a Stim-owned headless Chrome with its own profile. The page's console, failed requests and browser errors go to the workspace logs, `launched` reports whether the page loaded, `status` lists the page, and `stim reload web`, `stop`, `gc` and `worktree remove` reload or tear it down. The `web.url`, `web.ignoreCertificateErrors` and `web.viewport` settings choose the page, accept a dev server's self-signed certificate in the owned profile, and pick a desktop or phone viewport. `stim web` never starts a dev server: start Metro with `stim start`, or your own server on a port from `stim ports get`, first. With nothing serving the page it reports `launched: "unverified"` and prints the command that starts one. `stim guide web` documents it. ## Migration notes

- `stim web` does not start Metro for Expo web. Run `stim start`, then `stim web`. The `stim web --json` payload has no `devServer` field.
- `lastActivityAt` in `status` is rounded down to the minute.
- `status --watch` applies a log append no sooner than 15 seconds after the previous refresh, so a log-driven update, such as the error count or device activity, can lag by up to 15 seconds.
- `gc` no longer deletes a device only because its name or AVD `config.ini` matches Stim's format. A device created before the ledger that this home's config does not record in the device pool or as owned by a project is listed under `unverifiedDevices` with its delete command; run that command yourself to remove it.
- `ios --runtime` refuses when the workspace's simulator runs another iOS version. Remove the simulator with `stim worktree remove` or `stim gc --delete`, or pass `--slot <name>` to create one beside it.
- `gc --worktrees` and the idle sweep also remove clean worktrees whose pull request was merged or closed. A closed pull request whose remote branch is gone keeps a worktree with local commits.
- A launch whose app exited before the bundle wait ended now fails instead of returning `launched: "unverified"` or `"bundling"`.
- A build whose inputs changed while it ran is installed but not cached, so the next run with the same inputs compiles again.
- `gc --delete` trims Metro, client and device logs over 16 MiB to their newest 8 MiB.
- iOS "Synchronous URL loading" diagnostics no longer appear in `logs --errors`.
- `stim android` refuses before Gradle when no Android SDK is found. Set `ANDROID_HOME` or write `sdk.dir` into `android/local.properties`.
- In a monorepo, `ports`, `settings`, `logs`, `reload`, `stop` and `status` run from a package that depends on neither `react-native` nor `expo` act on the one Stim app registered in the same Git worktree. `ports stop` or `stop` there stops the app's ports or workspace. A package that already holds ports keeps them until you release them.
- Stim starts Stim Desktop without the command's `STIM_HOME`, so a simulator booted under another `STIM_HOME` does not appear in it. Pass `--simulator-app xcode` to see it.
