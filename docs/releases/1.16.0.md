# 1.16.0

Stim Desktop and the Stim phone app ship through their own workflows; this release covers the six npm packages. Commits that only changed those apps are not listed.

## New

**Remote device hosting**

- `stim ios --remote <machine>` runs an owned iOS simulator on an approved hosting Mac, as `stim macos --remote` and the Android hosting path already do. It uploads only the app files that changed, hands over an iOS build the same Mac ran for the client, and pulls the hosted app's native logs back for `stim logs`. [83ad52f](https://github.com/appandflow/stim/commit/83ad52f0f43a6c2d0a5b47044924a966cde92c0f), [785a19f](https://github.com/appandflow/stim/commit/785a19fa507709a4471883e87781055bdae6bb05)
- Desktop and the phone app view and control a hosted iOS simulator through stim-server's relay. [fae6cd2](https://github.com/appandflow/stim/commit/fae6cd2f94f6c6af451930e200ec9fa82a197ef0)
- Agents drive a hosted iOS simulator with agent-device. [14f1715](https://github.com/appandflow/stim/commit/14f171529a9ac1fc0b310a9f7ffde386f819c13c)

**Setting up stim-server**

- `stim-server setup` walks a Mac through becoming a stim-server host. stim-server issues setup tickets on access requests and serves a node-bound setup journal route; `stim doctor --fix` sends `STIM_ACCESS_TICKET` with its access requests, accepts only server-format tickets, and reports the host's permissions. [e958eea](https://github.com/appandflow/stim/commit/e958eea04c6536cbb0d6b5f5c446563c93b58f17), [cf587dd](https://github.com/appandflow/stim/commit/cf587dd5d319f3b5113076dd5b82d53694cdba48), [034a6da](https://github.com/appandflow/stim/commit/034a6da05d311b069fbd4fddf1b27331ab5ed1d4)

**Workspaces, status and maintenance**

- `stim worktree remove` keeps a removed workspace as an archived workspace, and stim-server serves its archived logs, agent actions and replays. `gc` has archived scopes. [ddd8543](https://github.com/appandflow/stim/commit/ddd8543981cbd2fc92ce964f829e2837f916dc5f), [9c05416](https://github.com/appandflow/stim/commit/9c0054168b2cb7a9bb9a76a99b7a18d5fd8a27e2)
- A report-only automatic maintenance engine in the CLI. [b4c9926](https://github.com/appandflow/stim/commit/b4c9926eb45a9ae7b27ebd945a1a41dd9b276372)
- `stats`, `gc` and Desktop Storage report agent-device and SwiftPM cache disk use. [daeafa5](https://github.com/appandflow/stim/commit/daeafa5ebf46e5618a4d65573ea78c75812dabe1)
- `status` reports `agentDevice.stateDir`, and agent-device state lives in the workspace. [44e7875](https://github.com/appandflow/stim/commit/44e787572dc3ca4203257d971173b338d2063c7f)
- `status --json` carries completed step durations and cache hit or miss for a build. [af5f3de](https://github.com/appandflow/stim/commit/af5f3de3081ae8be7b6149787f004528f2f64051)
- Run placements record `slotWaitMs`, and `doctor` adds a note on macOS when a Mac is a candidate for offloading builds. [aa848119](https://github.com/appandflow/stim/commit/aa848119d38577df6e7cc7a21e208c3317a48307)

## Fixes

- `stim ios` and `stim android` approve every URL scheme the app declares on owned simulators. [ac39538](https://github.com/appandflow/stim/commit/ac39538f310da4a2df40d1d5657be317241f4ded)
- `stim-server service install` waits for the old stim-server to release its port and fails when the new job exits. [3fa960b](https://github.com/appandflow/stim/commit/3fa960b0999f0c4da366c8dfa8a2cbb9cfada8bd)
- Hosted devices are deleted when a hosted session stops, and stopped sessions are retired at server start. [85612bb](https://github.com/appandflow/stim/commit/85612bbc60f32e8c87db17a5df41893abd44b29e)
- Old compiled helper builds are pruned. [5bd3bdc](https://github.com/appandflow/stim/commit/5bd3bdcbe4bc6533c06fdf0bf8fcd05333179ba8)
- `status` shows every platform an app supports. [9244fe5](https://github.com/appandflow/stim/commit/9244fe55e349afc8cfa5a86db3bd50f65504b976)
