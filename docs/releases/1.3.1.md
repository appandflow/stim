## Migration notes

Preserve existing Stim state when upgrading. No state reset is required.

Log queries now return `STIM_NO_PROJECT` when the workspace has no timeline. Run the command from the intended workspace after starting or building with Stim. Existing empty timelines still return an empty successful result.

Worktree warming no longer copies without an ownership claim. If it returns `STIM_CLAIM_UNAVAILABLE`, follow the reported process-identity or storage remedy before retrying.
