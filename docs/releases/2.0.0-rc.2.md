# 2.0.0-rc.2

Install `stim@2.0.0-rc.2` to try the second Stim 2.0 release candidate. The optional S3 cache provider is available as `@stim-cli/cache-s3@2.0.0-rc.2`.

## Fixes

- `stim stop` and `stim worktree remove` can finish on macOS when an iOS simulator log collector has exited but its log pipes remain open. [3a69ba46b2](https://github.com/appandflow/stim/commit/3a69ba46b283c6a4d5ead1c958cef61f49ec2da1)
- Repair the native release compatibility checks for Xcode and hosted Android. [84db9406a3](https://github.com/appandflow/stim/commit/84db9406a324f87d285e4b4be9a55b3510d25a47)

For upgrade steps, see the [Stim 2.0 upgrade guide](https://stim.appandflow.com/docs/migrate-to-2).
