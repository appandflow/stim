# 2.0.0-rc.1

This is the first Stim 2.0 release candidate. Install `stim@2.0.0-rc.1` to try it. The optional S3 cache provider is available as `@stim-cli/cache-s3@2.0.0-rc.1`.

- A resident `stimd` per Stim home owns Metro, device logs and maintenance. The `stim` package also provides `stim serve`, `stim service` and `stim ci`.
- Cleanup requests, Desktop item deletion and native-build headroom share the daemon’s cleanup queue. Run `stim gc --dry-run` to preview cleanup. Automatic discovery is off by default.
- macOS uses the shipped signed FSEvents helper to track filesystem changes for saved cleanup observations.

For upgrade steps and changes to configuration, service installation and cleanup scripts, see the [Stim 2.0 upgrade guide](https://stim.appandflow.com/docs/migrate-to-2).
