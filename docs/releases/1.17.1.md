# 1.17.1

Stim Desktop and the Stim phone app ship through their own workflows; this release covers the six npm packages. Commits that only changed those apps are not listed.

## Removed (breaking)

**Build machines and hosting machines are now remote Macs.** Settings, flags and environment variables are renamed with no migration and no aliases: the old names are no longer read. [59f8172db](https://github.com/appandflow/stim/commit/59f8172db9b127be3c6d601beed2bf50fc732112), [adca393d4](https://github.com/appandflow/stim/commit/adca393d4d93bce2832106319779d9e44e9076e2)

| Before                                        | Now                                                              |
| --------------------------------------------- | ---------------------------------------------------------------- |
| `offload.machines` and `hosting.machines`     | `remote.machines` (one list for build and device-host approvals) |
| `offload.machine`                             | `remote.build`                                                   |
| `--build-machine` (`ios`, `android`, `macos`) | `--remote-build`                                                 |
| `STIM_OFFLOAD_MACHINE`                        | `STIM_REMOTE_BUILD`                                              |
| `offload.mode`                                | `remote.buildMode`                                               |
| `STIM_OFFLOAD_MODE`                           | `STIM_REMOTE_BUILD_MODE`                                         |
| `offload.workerRoot`                          | `server.workerRoot`                                              |
| `offload.gradleDaemonIdleMinutes`             | `server.gradleDaemonIdleMinutes`                                 |
| `offload.maxLoadPerCore`                      | `server.maxLoadPerCore`                                          |
| `stim doctor --json` `buildMachines`          | `remoteMachines`                                                 |

`doctor --fix` now asks each machine in `remote.machines` for build and device-host approval, and reports a machine once when both checks name it.

## Behavior changes

- **`ios.remote` and `android.remote` are allowed at machine scope**, so one setting on this Mac applies to every project. [bff943280](https://github.com/appandflow/stim/commit/bff9432802f5179997dc9d28dbc5261781452a1c)

## New

- **`stim macos` builds report phases and progress.** `status --json` shows the build as `environments[].build` with platform `macos`: phases `prepare`, `compile`, `install` and `launch`, and during `compile` SwiftPM's `[done / total]` as `detail.unit: "steps"`. Finished runs and their phase times are in `environments[].builds.macos`, and macOS builds are labeled in machine usage. [8c36483a0](https://github.com/appandflow/stim/commit/8c36483a072b4ea0b7bafd9d44717bd1456d9c76)
- **`stim-server setup` prints concise output.** It shows one running line per step and the result, and `--verbose` prints the full step detail. The running line is cleared before an error is printed. [6b21927d7](https://github.com/appandflow/stim/commit/6b21927d776963164d0b8cbb32b81e2664dbd6ed)
- **`stim gc --cache archived-<kind>:<id>`** clears one kind of data from one archive. [449c76fa4](https://github.com/appandflow/stim/commit/449c76fa44643929ffc2bbb373a8496d6294c135)

## Fixes

- `stim-server setup` reads the host's Screen Recording and Accessibility permissions from the running service, so it no longer asks again for a permission that is already granted. [814a621f3](https://github.com/appandflow/stim/commit/814a621f311e4244018966d15ceced7af0ee1311)
- `stim-server setup` captures the login shell's environment in its own session, so an interactive shell no longer takes over the terminal's foreground process group and stops the command with SIGTTOU. [6b21927d7](https://github.com/appandflow/stim/commit/6b21927d776963164d0b8cbb32b81e2664dbd6ed)
- The hosted agent driver's error includes the agent-device proxy's stderr when the proxy exits before it is ready. [1e0ba5276](https://github.com/appandflow/stim/commit/1e0ba52765f69f6df8c1ac7628d2bd9c7b1f19c4)
- The full Windows unit suite stays green: server and worktree-refresh regression tests are synchronized. Test-only change. [71a41d613](https://github.com/appandflow/stim/commit/71a41d613c1891b74548a78ac86367fdf3092e09)

## Migration notes

- Rename every setting, flag and environment variable in the table above in your project config, machine config, scripts and CI. Nothing reads the old names.
- Merge `hosting.machines` into `remote.machines`. Run `stim doctor --fix` to request build and device-host approval from each listed Mac.
- Move `offload.workerRoot`, `offload.gradleDaemonIdleMinutes` and `offload.maxLoadPerCore` to `server.*` on the Mac that runs stim-server.
- Tools that read `stim doctor --json` must read `remoteMachines` instead of `buildMachines`.
