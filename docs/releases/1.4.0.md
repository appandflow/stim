# 1.4.0

## New

- Reserve named workspace ports for web and API servers with `stim ports get <label>`. List allocations with `stim ports`, stop listeners with `stim ports stop [label]`, or release reservations without killing with `stim ports release [label]`. Stop supports `--dry-run`; worktree removal and GC reclaim named allocations. Metro remains separate. [beeae86b8](https://github.com/appandflow/stim/commit/beeae86b81f846fb213b0c8fad0407d51b1fdbb8)

## Migration notes

Preserve existing Stim state when upgrading. Use the current CLI for cleanup after allocating named ports; older versions do not manage those allocations.

Named reservations do not hold sockets open. Pass the returned port to the server, use strict-port behavior when supported, and verify the bound port. `ports stop` may stop a listener outside the workspace, so reserve only services that workspace may stop.
