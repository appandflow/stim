# 1.12.0

## New

- `iosSimulatorApp` and `androidEmulatorApp` default to `stim-desktop` on macOS while Stim Desktop is installed, found by its bundle id through Launch Services. Without it the defaults stay `xcode` and `emulator`, and a set value always wins. `stim settings` shows such a default as `(default: Stim Desktop installed)` and `--json` adds `defaultReason`. [5ebf6ae](https://github.com/appandflow/stim/commit/5ebf6ae0d475499b2553dc440eb5914f411db574)
- `ios --plan` and `android --plan` report why they predict a cache miss, as `missReason` in the plan payload. [ae99e71](https://github.com/appandflow/stim/commit/ae99e7144d566557f72d5a372f77bd607be5d2a5)
- AVDs Stim creates get a hardware keyboard (`hw.keyboard=yes`) unless `android.avdConfig` or `android.avdConfigFile` sets it. A parked AVD from before this default gets the key when it is adopted. [f0f550f](https://github.com/appandflow/stim/commit/f0f550fb259ecf8ed84598b4d65cd294dbbed2d0)
- `stim status --json` reports structured `issues` (code, severity, message, remedy) beside `warnings`, and an owned emulator's `deviceProfile`. [52bfcb7](https://github.com/appandflow/stim/commit/52bfcb765a3ba1a6fe293e82aa637659d5bb5338), [8e072a3](https://github.com/appandflow/stim/commit/8e072a3d78aee5294ebd2c29dd45b8ded9844728)
- The machine setting `gc.worktreeGraceMinutes` (default 120, env `STIM_GC_WORKTREE_GRACE_MINUTES`) keeps a merged or idle worktree from `gc` until that long after its last activity. A booted owned device or an unexpired device lease also keeps a worktree. [4a23ae1](https://github.com/appandflow/stim/commit/4a23ae121ce36aafba43e2fb59b446f14409d1de)
- `@stim-cli/server`:
  - Paired devices with `control` can drive a Stim-owned simulator or emulator with touch, text and hardware buttons in a control session held under a `stim device lock` lease. [c1e6cb4](https://github.com/appandflow/stim/commit/c1e6cb4fab04ad7459598596c47669c31aaa00ff)
  - `input.rotate` and `input.posture` rotate a device, fold an iPhone Duo and move a foldable emulator's hinge. [d64d5ee](https://github.com/appandflow/stim/commit/d64d5ee733fd0b312f88319763ebe24d4104a20b)
  - `build.plan` runs one plan at a time per workspace. [80ca4de](https://github.com/appandflow/stim/commit/80ca4ded3f0f3809ac4e98b3a73e5f4c89851ecd)

## Fixes

- App id detection evaluates a dynamic `app.config.*` through `expo config`, so a non-literal `bundleIdentifier` or `package` is found before prebuild. [b22a317](https://github.com/appandflow/stim/commit/b22a31723948153600cc570d66e575525cc009d1)
- `android --device-profile` refuses a profile such as `pixel_fold` on a system image that cannot boot it, before building or creating an AVD. [5dd08fd](https://github.com/appandflow/stim/commit/5dd08fdf067510f87b73b71f5a27428143094215)
- `stim stop` closes only agent-device sessions that belong to this workspace's stopped device. [1b1ffb3](https://github.com/appandflow/stim/commit/1b1ffb3c9bbd69b1bc8e89781635730a8a9fb099)
- `stim status` no longer warns about an idle workspace's shut-down emulator or a supervisor record proven stale. `stop --slot` forgets that slot's launch record. [52bfcb7](https://github.com/appandflow/stim/commit/52bfcb765a3ba1a6fe293e82aa637659d5bb5338)
- A remote EAS start waits for another workspace's session start to finish, with a notice, instead of failing with `STIM_LOCK_TIMEOUT` after 4 minutes. [3f26806](https://github.com/appandflow/stim/commit/3f26806441eabb033805cbb7fcbff1b045f53855)
- `@stim-cli/server`:
  - A `logs.query` or `logs.subscribe` whose `slot` or `grep` cannot be a `stim logs` argument gets `bad-request` instead of closing the connection or stopping the server. [85ff2f8](https://github.com/appandflow/stim/commit/85ff2f8699af5f09ad2db323080d1f874bd791fe)
  - Simulator input from the frames helper keeps working on Xcode 27 after a CoreDevice client such as Device Hub has touched the simulator. [370fa2f](https://github.com/appandflow/stim/commit/370fa2f72ddfc76793cdbe27846193173d2d31a8)

## Docs

- Quitting Device Hub on Xcode 27 shuts down every booted simulator on the machine, not only the ones it opened. [ff21e53](https://github.com/appandflow/stim/commit/ff21e53c61440943ce8de9c73b90e0c40173097c)

## Migration notes

- With Stim Desktop installed and neither viewer setting set, owned simulators open in Stim Desktop and owned emulators boot without a window. To keep the device windows, run `stim settings set iosSimulatorApp xcode` and `stim settings set androidEmulatorApp emulator`.
