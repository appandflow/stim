# 1.0.0-rc.18

When Stim is not installed globally, replace `stim` with `npx stim-cli`.

## Fixes

- Warming an Android worktree excludes generated autolinking caches, including nested apps, so Gradle resolves native dependencies inside the new checkout. [1fac645](https://github.com/appandflow/stim/commit/1fac64578868b3b9cb0f2142105907a7507eb0e7)
- Keep large temporary copies on the operation's volume, including worktree warming and cached app preparation. `STIM_TMPDIR` or machine `tempDir` overrides placement; doctor reports cross-volume copies. [20232f3](https://github.com/appandflow/stim/commit/20232f32c6288339d8820dac7fc8afe2e6da9df5)
- Repair stale Android CMake launcher configurations with `stim doctor --fix --platform android`, including installed native modules. Stop all native builds before repair; custom launchers and shared ccache entries are preserved. [008d057](https://github.com/appandflow/stim/commit/008d057947a00ca45093a8291c7ad3fd60db2c6d)
- Validate benchmark cache entries with the pinned CLI's fingerprint library. [0079fb3](https://github.com/appandflow/stim/commit/0079fb3ae18a05d1222c6f56d31a4e4bb928140c)
- Audit benchmark device-session scoping per shell command, accepting correctly scoped delayed navigation and rejecting unscoped invocations later in a chain. [782b8c5](https://github.com/appandflow/stim/commit/782b8c5046cf300fb54dddf509ca9240cdb61cf5)

## Docs
