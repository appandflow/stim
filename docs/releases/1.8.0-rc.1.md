# 1.8.0-rc.1

## New

- Choose Siniulator or Apple's viewer with the machine-wide `iosSimulatorApp` preference. Override it for one local launch with `stim ios --simulator-app siniulator` or `--simulator-app xcode`, including an already running owned simulator. The override does not change the saved preference. [072ddc7c5](https://github.com/appandflow/stim/commit/072ddc7c5a2c25c112addc379c2cce490b23887d), [5600b9e26](https://github.com/appandflow/stim/commit/5600b9e26c4ef75bcf33d53984dddd1f01b3a5a0)

## Fixes

- Open owned simulators with the selected Xcode's Device Hub on Xcode 27, with Simulator retained for older Xcode versions. Window opening remains best effort. [642606173](https://github.com/appandflow/stim/commit/642606173c70581c3e2866ce50c90e954391a608)
- Verify Cloudflare Quick Tunnels and remote Metro reachability when the system DNS resolver still has a stale answer for a new tunnel hostname. [9c9ac0d8e](https://github.com/appandflow/stim/commit/9c9ac0d8ed476da75d9c2b8f08e39d25043243ce)

## Docs
