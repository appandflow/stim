# 1.7.0

## New

- The Android development loop runs on Windows, including owned emulators, Metro supervision, native builds, installation, logs, worktrees, and caches. [183f05b8e](https://github.com/appandflow/stim/commit/183f05b8e), [f5a6df25d](https://github.com/appandflow/stim/commit/f5a6df25d), [f700814d9](https://github.com/appandflow/stim/commit/f700814d9), [156117682](https://github.com/appandflow/stim/commit/156117682)
- `stim ios --remote eas --eas-profile <profile>` works from a Windows host using a completed EAS development build and a remote simulator. [f1753ee8c](https://github.com/appandflow/stim/commit/f1753ee8c), [9a8aaff2f](https://github.com/appandflow/stim/commit/9a8aaff2f)

## Removed (breaking)

- Node 20 support ended. Running Stim requires Node 22.12.0 or later. [87285918d](https://github.com/appandflow/stim/commit/87285918d)

## Fixes

- Windows Android runs retain the selected emulator ABI across repeated slots and wait for the emulator's package manager before installing. [3b5aea298](https://github.com/appandflow/stim/commit/3b5aea298)
- Windows claim acquisition yields between transient publish retries, avoiding a spurious refusal when other processes repeatedly remove and recreate the claim directory. [8e8ac8e10](https://github.com/appandflow/stim/commit/8e8ac8e10)
- Windows worktree removal handles long paths, and claim acquisition treats an access denial for a disappearing claim as a retryable absence. [7855bbe46](https://github.com/appandflow/stim/commit/7855bbe46), [a5ff2b896](https://github.com/appandflow/stim/commit/a5ff2b896)
- Windows release APK swaps and named Metro ports work without Unix `cp`, `mv`, `zip`, or `lsof` commands. [23c13116e](https://github.com/appandflow/stim/commit/23c13116e)
- Windows Android builds report insufficient native path room before Gradle runs. Supervisor startup no longer inherits a pipe that keeps the parent waiting, and emulator cleanup handles the crash-consent process. [156117682](https://github.com/appandflow/stim/commit/156117682)
- Bare React Native launch remedies no longer suggest opening Expo's development-server picker. [589bfe032](https://github.com/appandflow/stim/commit/589bfe032)
- Android emulator debug launches route Metro through the existing ADB reverse connection, so a cached install can load its bundle on a newly started emulator. [095797d7f](https://github.com/appandflow/stim/commit/095797d7f)
- iOS simulator launches recover when CoreSimulator reports no process handle even though the app started, after confirming the app was absent before launch and running afterward. [18c7cae7f](https://github.com/appandflow/stim/commit/18c7cae7f)
- Clean worktree removal recognizes `@`-prefixed branch names when checking for unique commits. [2800d7279](https://github.com/appandflow/stim/commit/2800d7279)

## Migration notes

Upgrade to Node 22.12.0 or later before installing this release. Repository development requires Node 22.18.0 or later. On Windows, use a short project path or a `subst` drive for Android native builds; the requirements page lists the host tools and the remote iOS path.
