# 1.0.0-rc.17

If Stim is not installed globally, replace `stim` below with `npx stim-cli`.

## Fixes

- Android builds disable CMake precompiled headers by default when Stim supplies ccache, improving compiler-cache reuse across worktrees. Explicit project PCH settings are preserved; builds without Stim's ccache setup and iOS builds are unchanged. The tradeoff is slower cold C++ compilation. ([9418d3d](https://github.com/appandflow/stim/commit/9418d3d75e251ce5c17c569a443c217a1ee4d1ac))
- The repository's benchmark harness flags missing or below-target Android compiler-cache evidence, retains failed attempts for investigation, and excludes them from published comparisons. Android preparation and preflight also require a doctor report without cost findings. ([872bb1f](https://github.com/appandflow/stim/commit/872bb1f09616fa0c95a377e191ec105b82069837))

## Docs

- `stim guide agent` keeps the workflow, safety rules, and recovery actions up front. Optional cache warm-up, ABI selection, fingerprint fallback, and build-sharing details live in the build and concurrency guides. ([1c420aa](https://github.com/appandflow/stim/commit/1c420aa182d09d8f6e0b4b6b1982e52fc9c0fdef))
