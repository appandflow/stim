# 1.20.1

Stim Desktop and the Stim phone app ship through their own workflows; this release covers the seven npm packages (`@stim-cli/core`, `@stim-cli/cache`, `@stim-cli/metro`, `@stim-cli/expo-build-cache`, `stim`, `@stim-cli/ci` and `@stim-cli/server`). Commits that only changed those apps, tests or internal structure are not listed.

## Fixes

- npm install and npx no longer print the uuid@7 deprecation warning; Xcode project files are read by an in-tree parser. `stim` drops the `xcode` runtime dependency that 1.20.0 added and keeps `@xmldom/xmldom`. [e8f149943](https://github.com/appandflow/stim/commit/e8f1499432271732ad07e6cdcf79788795740075)

## Docs

- `stim guide tutorial run` has the agent check each change on the simulator with agent-device after the after screenshot (tap the button, toggle the switch, type a name, take a screenshot), so Stim Desktop records the actions for replay; when agent-device is not installed it checks the build result and `stim logs --errors` instead and does not install it unasked. The "Change It Again in Parallel" step has a copyable prompt that asks for a new worktree. The `stim guide tutorial manual` section is removed and now answers "Unknown section"; the website's Desktop and getting-started pages no longer link it. [52eba84c7](https://github.com/appandflow/stim/commit/52eba84c729ff50f287c52df8051d3aa1adcb21a)
- The `ios.scheme` description in `stim settings` and the shipped JSON Schema says the `--scheme` flag overrides it, and the website's settings tables are generated from the settings registry. (`@stim-cli/core`) [b52e08b6a](https://github.com/appandflow/stim/commit/b52e08b6aba6d3efa23ba7e4c7d93996cd40b25f)
